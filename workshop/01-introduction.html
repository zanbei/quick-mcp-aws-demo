    模块 1 · 步骤 2

    为什么用 MCP

    MCP（Model Context Protocol，模型上下文协议）是连接 AI 应用与外部数据、工具的开放标准，可以理解为“AI 应用的 USB 接口”。工具方按统一格式暴露能力（tools/list），AI 应用按统一格式发现并调用（tools/call），不必为每个系统写一套专用集成。

    MCP 客户端

    AI 应用一侧，例如 Amazon Quick、Kiro。它连接服务端，把工具交给模型选择和调用。

    MCP 服务端

    暴露工具的一侧，每个工具有名称、描述和参数定义。例如 execute_query、QueryKnowledgeBases。

    一次调用

    客户端 tools/list 发现工具，模型决定调哪个，tools/call 执行并返回结果。

    在本方案里，Amazon Quick 是 MCP 客户端，awslabs 开源的各服务 MCP server 是服务端。
